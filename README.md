# Xamidxonov Yoqub — портфолио

Статический сайт на русском: HTML, CSS и JavaScript, без сборки и зависимостей.

Full-stack IT expert: дизайн, разработка и запуск цифровых продуктов.

Структура: плавающая навигация с индикатором раздела; первый экран с туром по OneSim (вкладки с автопереключением и лентой событий); кейсы OneSim (bento-сетка, схема webhook, все экраны) и White Ray (просмотрщик с вкладками, схема единой базы); услуги во вкладках с примерами из проектов и этапами работы; опыт с логотипами UZINFOCOM, HELIX GROUP и Sejong University; инструменты по категориям; контакт. Скриншоты административного портала не используются.

Шрифт Onest подключается из Google Fonts.

Локальный просмотр:

```sh
python3 -m http.server 4186 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4186. Галерея поддерживает стрелки клавиатуры, свайп, Escape и переключение между просмотром по ширине и вписыванием в экран. Вкладки управляются стрелками. Анимации учитывают настройку уменьшения движения.
